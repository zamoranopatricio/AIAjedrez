# Binarios de Stockfish

Esta carpeta almacena los binarios locales del motor Stockfish para diferentes plataformas:

- **Windows**: Ubica aquí `stockfish.exe` o `stockfish-windows-x86-64-avx2.exe`.
- **Linux**: Ubica aquí `stockfish` ejecutable (o instala mediante `sudo apt install stockfish`).

`src/platform_utils.py` detectará automáticamente el archivo adecuado según el sistema operativo.
